## รายละเอียดโปรเจกต์

โปรแกรมเว็บแอปพลิเคชันสาธิตระบบวาดภาพดิจิทัลสไตล์ MS Paint ยุคคลาสสิก พัฒนาโดยใช้ **HTML5 Canvas** และ **Pure JavaScript** โดยการจัดการพิกเซลโดยตรงผ่าน `ImageData` (Direct Pixel Manipulation) ร่วมกับอัลกอริทึมทางคอมพิวเตอร์กราฟิกพื้นฐาน (Primitives Algorithms) โดยไม่ใช้ API ลากเส้นสำเร็จรูปของ Canvas

## วิธีการควบคุมการทำงาน (Interaction)

- **การวาดภาพ (Drawing):** คลิกเมาส์ค้างแล้วลาก (Mouse Click & Drag) บนพื้นที่ Canvas
- **การเลือกเครื่องมือ (Tool Selection):** คลิกเลือกปุ่มเครื่องมือที่ต้องการในแถบด้านซ้าย
  - **ดินสอ (Pencil):** วาดเส้นอิสระ
  - **ยางลบ (Eraser):** ลบพื้นที่ด้วยสีขาว
  - **เส้นตรง (Line):** คลิกจุดเริ่มต้นแล้วลากวางเพื่อสร้างเส้นตรง
  - **สี่เหลี่ยม (Rectangle):** คลิกค้างแล้วลากเพื่อกำหนดขนาดสี่เหลี่ยม
  - **วงรี (Ellipse):** คลิกค้างแล้วลากเพื่อกำหนดรัศมีวงรี/วงกลม
- **การเลือกสี (Color Selection):** คลิกเลือกเฉดสีที่ต้องการจาก **Color Palette** บริเวณด้านล่างของหน้าจอ
- **การปรับความหนาเส้น (Line Thickness):** ปรับสไลเดอร์ความหนาเส้น (1px - 10px) ที่แถบเครื่องมือด้านซ้าย
